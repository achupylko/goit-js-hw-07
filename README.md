# GoIT Homework — JavaScript Module 7

## 📘 Опис проєкту

Цей репозиторій містить домашнє завдання з **модуля 7 JavaScript** курсу
**Fullstack Developer** від **GoIT**. Мета модуля — навчитися працювати з
**об’єктною моделлю документа (DOM)**, маніпулювати DOM-деревом та обробляти
**події браузера**, зокрема події елементів форм.

---

## 🎯 Результати навчання (Module 7)

Після опрацювання матеріалів модуля ти:

- Розумієш, що таке **об’єктна модель документа (DOM)** та як будується
  **ієрархія DOM-елементів**.
- Знаєш основні **властивості та атрибути DOM-елементів**.
- Вмієш **маніпулювати DOM-деревом**:
  - створювати елементи;
  - додавати їх у документ;
  - видаляти елементи з DOM.
- Розумієш сутність та функціонал **подій у браузері**.
- Обробляєш події з використанням:
  - `addEventListener()`
  - `removeEventListener()`
- Застосовуєш **події елементів форм** для взаємодії з користувачем.
